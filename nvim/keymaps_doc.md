# Neovim 快捷键说明文档

本文件根据 `lua/keymaps.lua` 自动生成，便于查阅和自定义。

---

## Leader 键
- Leader 键设为：空格（Space）

## 常用快捷键
| 模式   | 快捷键         | 功能描述                   |
|--------|----------------|----------------------------|
| 插入   | jj             | 退出插入模式（Esc）        |
| 普通   | <Leader>w      | 保存当前缓冲区             |
| 普通   | <Leader>q      | 退出 Neovim                |
| 普通   | <Leader>c      | 关闭当前缓冲区             |
| 普通   | <Leader>h      | 源/头文件切换（Clangd）    |
| 普通   | <Leader>e      | 打开/关闭 NvimTree 文件树   |

## 窗口导航与调整
| 模式   | 快捷键         | 功能描述                   |
|--------|----------------|----------------------------|
| 普通   | Ctrl+h         | 移动到左侧窗口             |
| 普通   | Ctrl+j         | 移动到下方窗口             |
| 普通   | Ctrl+k         | 移动到上方窗口             |
| 普通   | Ctrl+l         | 移动到右侧窗口             |
| 普通   | Ctrl+↑         | 减小窗口高度               |
| 普通   | Ctrl+↓         | 增加窗口高度               |
| 普通   | Ctrl+←         | 减小窗口宽度               |
| 普通   | Ctrl+→         | 增加窗口宽度               |

## 视觉模式（Visual）
| 模式   | 快捷键         | 功能描述                   |
|--------|----------------|----------------------------|
| 视觉   | <              | 左移并保持选区             |
| 视觉   | >              | 右移并保持选区             |

## nvim-treesitter 相关
| 模式   | 快捷键         | 功能描述                   |
|--------|----------------|----------------------------|
| 普通   | gss            | 初始化选区（AST节点）       |
| 普通   | gsi            | 按 AST 节点递增选区        |
| 普通   | gsc            | 按作用域递增选区           |
| 普通   | gsd            | 递减选区                   |
