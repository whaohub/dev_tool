# Trouble.nvim 快捷键说明

本文件根据 `lua/config/trouble.lua` 自动生成，便于查阅和自定义。

---

## Trouble 面板内快捷键
| 快捷键         | 功能描述                 |
|----------------|--------------------------|
| ?              | 帮助                     |
| r              | 刷新                     |
| R              | 切换自动刷新             |
| q              | 关闭 Trouble 面板        |
| o              | 跳转并关闭 Trouble       |
| <Esc>          | 取消/关闭                |
| <CR>           | 跳转到选中项             |
| <2-leftmouse>  | 鼠标左键跳转             |
| <C-s>          | 跳转并水平分屏           |
| <C-v>          | 跳转并垂直分屏           |
| } 或 ]]        | 下一个问题项             |
| { 或 [[        | 上一个问题项             |
| i              | 检查项详细信息           |
| p              | 预览问题项               |
| P              | 切换预览                 |

## 折叠相关快捷键
| 快捷键         | 功能描述                 |
|----------------|--------------------------|
| zo             | 打开折叠                 |
| zO             | 递归打开折叠             |
| zc             | 关闭折叠                 |
| zC             | 递归关闭折叠             |
| za             | 切换折叠                 |
| zA             | 递归切换折叠             |
| zm             | 增加折叠                 |
| zM             | 关闭所有折叠             |
| zr             | 减少折叠                 |
| zR             | 打开所有折叠             |
| zx             | 更新折叠                 |
| zX             | 更新所有折叠             |
| zn             | 禁用折叠                 |
| zN             | 启用折叠                 |
| zi             | 切换折叠启用状态         |

---

如需 Trouble 面板的全局打开/关闭快捷键（如 `<Leader>xx`），请在主配置或 keymaps.lua 查阅或补充。
